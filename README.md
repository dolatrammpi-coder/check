# Zikson Prime Enterprise — Standalone

Standalone local recreation of the Zikson Prime Enterprise storefront extracted from the Apper-built source.

Run:
1. Install Node.js 20+.
2. npm install
3. npm run dev

Included: storefront design, responsive styling, product/category data, cart, search, category filtering, wishlist toggle and newsletter interaction. Apper SDK/runtime dependencies are removed.
